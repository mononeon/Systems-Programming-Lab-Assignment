System Programming & Microprocessor Laboratory (8086 MASM)

Design and Implementation of a Classical Caesar Cipher Simulator (+3 Shift) in Intel 8086 MASM Architecture

Source File: CAESAR.ASM  |  Target Architecture: Intel 8086 (16-Bit Real Mode, .MODEL SMALL)  |  Interrupt Interface: MS-DOS INT 21h

1. Executive Summary & System Specification

This report presents the architectural design, modular arithmetic formulation, and 16-bit assembly language implementation of the classical Caesar Cipher developed for the Intel 8086 microprocessor using the Microsoft Macro Assembler (MASM). The program fulfills three core laboratory objectives:

  • a. Buffered User Plaintext Input: Reads an arbitrary plaintext string from the keyboard via MS-DOS Interrupt 21h, Function 0Ah (with automatic fallback to "HELLO" if empty input is entered).
  • b. Forward Encryption (+3 Shift): Shifts every alphabetic character by $K = +3$ positions down the alphabet ($E(x) = (x + 3) \bmod 26$), handling circular wrap-around past 'Z' (5Ah) and 'z' (7Ah) while preserving non-alphabetic symbols and spaces.
  • c. Reverse Decryption (-3 Shift): Applies the inverse transformation ($D(x) = (x - 3) \bmod 26$) on the ciphertext buffer to deterministically reconstruct the original plaintext string, displaying a real-time cycle-by-cycle hexadecimal and character trace on the console.

2. Mathematical Formulation & ASCII Boundary Arithmetic

In classical cryptography, the 26 letters of the Latin alphabet are mapped onto the ring of integers modulo 26, $\mathbb{Z}_{26} = \{0, 1, \dots, 25\}$ (EITCA Modular Arithmetic Reference). For a plaintext ordinal $P \in \mathbb{Z}_{26}$ and shift key $K = 3$:

Encryption Function:   $C = E_3(P) = (P + 3) \bmod 26$
Decryption Function:   $P = D_3(C) = (C - 3) \bmod 26 \equiv (C + 23) \bmod 26$

On the 8086 microprocessor, using the hardware DIV instruction to compute modulo 26 requires 80–90 clock cycles per byte. Instead, CAESAR.ASM implements modular wrap-around directly in the ASCII domain using fast 3-cycle ADD/SUB instructions and unsigned boundary comparisons:

  • Uppercase Encryption (41h to 5Ah): Compute AL = AL + 3. If AL > 5Ah ('Z'), subtract 1Ah ($26_{10}$) to wrap around to 'A'–'C'.
  • Lowercase Encryption (61h to 7Ah): Compute AL = AL + 3. If AL > 7Ah ('z'), subtract 1Ah ($26_{10}$) to wrap around to 'a'–'c'.
  • Uppercase Decryption (41h to 5Ah): Compute AL = AL - 3. If AL < 41h ('A'), add 1Ah ($26_{10}$) to wrap around to 'X'–'Z'.
  • Lowercase Decryption (61h to 7Ah): Compute AL = AL - 3. If AL < 61h ('a'), add 1Ah ($26_{10}$) to wrap around to 'x'–'z'.

AX AH / AL Accumulator & System Call Selector AL holds the active byte for ADD/SUB cipher shifts and XLAT hex translation; AH selects DOS INT 21h subfunctions (0Ah, 09h, 02h, 4Ch).
BX BH / BL Trace Register Pair & Base Pointer BL stores the input byte before shifting; BH stores the output byte after shifting for PRINT_TRACE_ROW; BX indexes string length termination.
CX CH / CL Hardware Loop Counter Loaded with ACTUAL_LEN to control LOOP ENCRYPT_LOOP and LOOP DECRYPT_LOOP.
DX DH / DL I/O Pointer & Character Output DX holds effective string addresses (LEA DX, ...); DL passes single ASCII bytes to INT 21h / AH=02h.
SI 16-Bit Index Character Array Index (0..N-1) Steps sequentially through PLAINTEXT[SI], ENCRYPTED_STR[SI], and DECRYPTED_STR[SI].
